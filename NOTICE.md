## Lexique — French lexical database

- **Author:** Boris New & Christophe Pallier
- **Upstream:** <http://www.lexique.org/>
- **In this repo:**
  - `data/Lexique4/Lexique4.tsv` — the source database, unmodified
  - `data/lexicon/<letter>.json` — **derived work**, generated by `scripts/build-lexicon.js` (top 30k surface forms)

**⚠️ Licence not yet confirmed — action required before wide distribution.**
The Lexique site is HTTP-only and states its terms on the site rather than in
the download, so the redistribution terms for the bundled `.tsv` have not been
verified against a primary source. If they turn out to prohibit redistribution,
the fix is to untrack `data/Lexique4/Lexique4.tsv` and have contributors
download it themselves — `data/lexicon/` (what the extension actually loads)
would be unaffected, and `.gitignore` already has the rule to do it, commented
out. Academic use should cite:

> New, B., Pallier, C., Ferrand, L., & Matos, R. (2001). Une base de données
> lexicales du français contemporain sur internet: LEXIQUE. *L'Année
> Psychologique, 101*, 447–462.

## What this project does *not* bundle

No analytics, no telemetry, no advertising SDK, no crash reporter, and no
runtime network dependency. Translation runs on-device through Chrome's
built-in `Translator` API. The one exception is speech recognition in the
Practice tab, which is Chrome's own Web Speech API and is **not** on-device —
see [`pages/privacy.html`](pages/privacy.html).
